# Wheel Trader

INFR3120 Web and Scripting Programming, Fall 2026, Group 7

A used car marketplace. Sellers post a car with the "Sell Your Car" form, and the listings show as cards on the home page.

## Running

```
npm install
npm start
```

Open http://localhost:3000

## Code sources

Most of the code follows the INFR3120 lectures (express-generator setup, Express routing with `res.render`, Bootstrap, Font Awesome). Code not covered in the lectures is listed below.

| Code | File | Source |
|---|---|---|
| `router.post`, `req.body` and `res.redirect` in the route that saves a new listing | `routes/index.js` | Express documentation, https://expressjs.com |
| EJS `<% %>` tags used to loop through the listings | `views/index.ejs` | EJS documentation, https://ejs.co |
| Bootstrap classes (grid, cards, forms, buttons) | `views/*.ejs` | Bootstrap documentation, https://getbootstrap.com |
| Icons | `views/*.ejs` | Font Awesome Free, https://fontawesome.com |
